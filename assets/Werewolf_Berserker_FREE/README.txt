WEREWOLF BERSERKER - Pixel Art Character Asset  (FREE version)

CONTENTS
  - Idle  (idle)
  - Walk  (walk)
  - Skill 1 - Savage Claw Combo  (skill1_claw_combo)

FORMAT
  - Transparent PNG, 88x88 px frames (character base size 64x64), shadow baked into every frame
  - frames/<animation>/<direction>/<animation>_<direction>_NN.png
  - spritesheets/<animation>.png : one row per direction (S, SE, E, NE, N, NW, W, SW), one column per frame
  - animations.json : frame counts per direction and suggested frame time (ms)
  - Frames are anchored at the feet at about (44, 74) inside each 88x88 frame
  - Attack animations contain NO visual effects (slash trails, dust, shockwaves) - add your own

This FREE version includes Idle, Walk and Skill 1. The FULL version adds Skill 2 (Pounce), Skill 3 (Ground Slam), Roar and Growl.
